Static HTML/CSS/JavaScript, including original procedural graphics. Inquiry forms validate and preview locally; no personal information is submitted or stored by the site. No booking, payment, order or real WhatsApp backend is configured.

For GitHub Pages, publish the main branch root. All paths are relative and .nojekyll disables Jekyll processing. No install or build command is required. The repository contains demo source only, not campaign, lead, Gmail or payment records.
