# Original concept visuals and closing stories

These files support Durgesh Kumar's fictional portfolio concepts. Architectural and automotive scenes were generated with the built-in image generation tool, then encoded as JPEG for web delivery without changing image content. They do not show real properties, actual stock or client work.

`closing.css` and `closing.js` provide original scroll-based closing chapters, botanical/textile illustrations, pause controls and reduced-motion alternatives. No customer data is collected or transmitted.
